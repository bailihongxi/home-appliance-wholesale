# 家电批发进销存记账软件（电器版）

零部署、可离线、手机 + 电脑双端可用的**家电批发/零售**进销存记账工具。
无需服务器，数据全部保存在本机浏览器（IndexedDB）。

由桌面《Shoes and clothing ERP》（鞋服店进销存 V3）按「方案 A 纯换皮 + 简化商品模型」改造而来。

## 功能范围

- 商品档案：**品牌 / 型号 / 类型 / 单位 / 成本 / 批发价 / 零售价 / 库存 / 备注**（+ 原厂条码），无编码、无属性
- 进货 / 销售 / 赠送 / 退货 / 盘点 全业务闭环：单据自动联动库存、收支流水、欠款
- 开单支持 **批发价 / 零售价** 切换成交
- 扫码：手机/扫码枪扫**机身原厂条码或二维码**定位商品（查库存 / 开单加行）
- 记账中心（供应商应付 / 客户应收）、三层利润报表、首页经营看板
- 一键备份 / 导入恢复 / 打开密码 / 操作日志
- V3 多店铺多账号（数据隔离、经营范围过滤、GitHub 云同步）

## 运行方式

### 电脑本地（最简单）
直接浏览器**双击 `erp/index.html`** 即可打开使用（运行于 `file://`）。
> 注意：`file://` 下无法实时摄像头扫码（需 https），会自动降级为「拍照识别 + 手输」，其余功能完全正常。

### 手机端（功能最全）
1. 将整个 `erp/` 目录上传到任意免费 https 静态空间（GitHub Pages / 对象存储 / Netlify 等）。
2. 手机浏览器打开该地址 → 点「添加到主屏幕」→ 像 App 一样打开，此时**实时扫码**可用。
3. 配合 Service Worker（`sw.js`）缓存后，断网仍可打开使用。

## 备份纪律（重要）

数据只存在本机浏览器，清缓存 / 换手机 / 重装浏览器都会丢数据：

- **每天**在「我的 → 设置 → 导出备份」导出一份账本 JSON（`电器店备份_*.json`）。
- 电脑硬盘 + 网盘**各存一份**。
- 首页会显示「N 天未备份」提醒条，看到就导出。
- 导入备份会**整体覆盖**当前数据，导入前会二次确认。

## 目录结构

```
erp/
├── index.html             # 唯一入口（SPA 外壳）
├── manifest.webmanifest   # PWA：添加到主屏幕
├── sw.js                  # Service Worker（离线缓存，仅 https 生效）
├── css/                   # base / mobile / desktop / print
├── js/
│   ├── core/              # 纯逻辑层（可 Node 单测，不碰 DOM）
│   ├── store/             # IndexedDB 封装 + 工作上下文
│   ├── ui/                # 路由 + 组件 + 各页面
│   ├── barcode/           # 扫码（原厂条码 / 二维码）
│   └── app.js             # 启动、落库、锁屏
├── vendor/xlsx.full.min.js # CSV/Excel 导入
└── tests/                 # node --test 全部用例
```

## 技术栈

- 原生 JS（无框架、无构建、无 npm 依赖），经典 `<script>` 按序加载 + 全局 `window.ERP` 命名空间。
- 不使用 ES Module（`file://` 下 `<script type="module">` 会被 CORS 拦截）。
- 第三方能力以本地文件随包发布，离线可用。
