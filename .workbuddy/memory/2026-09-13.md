## V3.51（SW v80）手机端选货区右侧排版优化 — 推送部署

**需求**：V3.50 选货区在手机端单行已能容纳，但用户希望右侧「加入」按钮更紧凑、更有视觉识别：
1. 将库存数字放置到 加入按钮前面（即左侧，靠近品牌+型号卡片信息那侧）
2. 加入按钮两个汉字「加入」从横排排版更改为竖排排版
3. 加入按钮宽度收缩 30%（≈30px）、高度增大 50%（≈45px）
4. 加入按钮排布位置不变（仍在卡片右侧）

**实现（仅 `css/mobile.css` `@media (max-width:599px)`，电脑端 ≥600px 沿用 V3.50 不变）**：
- `.pick-side`：`flex-direction: column` → `row`，`align-items: center; gap: 8px`（库存数字与按钮横向并排）
- `.pick-side .pick-stock { order: 0 }`：库存前置
- `.pick-side .btn { order: 1; width: 30px; height: 45px; padding: 0; line-height: 1; font-size: 13px; letter-spacing: 0; writing-mode: vertical-rl; text-orientation: upright }`：
  - `writing-mode: vertical-rl` 让「加入」两个汉字沿竖直方向排版（加 上、入 下）
  - `text-orientation: upright` 保证汉字保持正立（不旋转 90°）
  - 按钮宽度 30px（基础 `.btn-sm` 约 44px，-30%）、高度 45px（min-height 30px + 50%）
