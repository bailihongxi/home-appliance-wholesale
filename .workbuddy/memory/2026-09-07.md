### 部署步骤（保留供下次复用）
1. `git worktree add /tmp/gh-pages-worktree gh-pages` 创建工作区
2. `git fetch origin gh-pages` 拉取远程最新（可能含手机端自动同步的 `chore(sync)` 提交）
3. `git reset --hard origin/gh-pages` —— 重要：必须以远程最新数据为准（不是本地 gh-pages）
4. 清空工作区但保留 `.nojekyll` 和 `data/`：`find ... ! -name 'data' ! -name '.nojekyll' -exec rm -rf {} +`
5. `cp -R erp/. .` 把 V3.17 代码叠加上来
6. 清理 `rm -rf .preview .DS_Store`
7. `git add -A && git commit -m "deploy(gh-pages): ..." && git push origin gh-pages`
8. `git push origin main`
9. 清理：`git worktree remove /tmp/gh-pages-worktree --force`

### 注意事项
- 远程 gh-pages 经常有 `chore(sync): 手机端账本同步 ...` 自动提交（来自设备云同步），不要 force-push 会丢失用户数据
- WebFetch 访问 bailihongxi.github.io 命中 CDN 缓存，可能显示旧版本；用 raw.githubusercontent.com 验证实际部署
